# 📦 Bolcan

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)

**Bolcan** is a high-performance Python library engineered to bridge the gap between complex industrial formulas and scalable software. Originally developed for Petroleum Engineering, it provides a suite of optimized tools for material balance, fluid dynamics, and reservoir evaluation.

## 🚀 Key Features
* **Engineering Kernels:** Pre-built functions for Material Balance and Well Testing simulations.
* **Numerical Precision:** Implements rigorous numerical methods for fluid flow and pressure calculations.
* **Modular Architecture:** Designed as a plug-and-play library for developers to integrate engineering calculations into larger Python ecosystems.

## 🛠 Tech Stack
* **Language:** Python
* **Computation:** NumPy, Math-heavy algorithmic logic
* **Methodology:** Object-Oriented Programming (OOP)
